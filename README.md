# Python Weather API

## Project Description

This project is a Python-based Weather API application that fetches current weather information using an online weather API.

The application allows users to search for cities and view their current temperature, humidity, feels-like temperature, and wind speed.

## Objectives

- Fetch data from a weather API
- Use the Python requests module
- Parse JSON responses
- Display weather information clearly
- Provide city search and filtering
- Handle invalid user input and API connection errors

## Technologies Used

- Python
- Requests
- JSON
- Open-Meteo Weather API

## Features

### 1. Weather Information

The user can enter a city name and retrieve:

- Temperature
- Humidity
- Feels-like temperature
- Wind speed

### 2. Search and Filter

Users can search for a city using part of its name.

Example:

```text
Search: del
Result: Delhi
